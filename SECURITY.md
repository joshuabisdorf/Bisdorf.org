# Security Policy

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could expose private data,
credentials, deployment details, or an exploitable weakness.

Use GitHub private vulnerability reporting for this repository when that option
is available. If it is unavailable, use the contact method published on
https://www.bisdorf.org and clearly identify the message as a security report.

Include enough information to reproduce and assess the issue, but do not include
unnecessary personal data, credentials, or secrets.

## Scope

Security reports may include problems in the repository source, generated site,
Cloudflare-facing configuration, dependency usage, or build/deployment process.
Third-party services and projects linked from the portfolio are outside this
repository's security scope unless the issue is caused by this site's integration
with them.

## Disclosure

Please allow reasonable time to investigate and remediate a valid report before
publishing technical details.
